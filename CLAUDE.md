# Repository guide

Public archive of talks, lectures and technical notes, with the Quantum Notebook static website.

Read [agent/NOTES.md](agent/NOTES.md) and [docs/MAINTENANCE.md](docs/MAINTENANCE.md) before adding or changing materials. Preserve published file paths, item IDs, series names and frozen citation keys. Curated metadata belongs in tools/catalog_overrides.json; catalog.json is generated.

Run the catalog, thumbnail, size and website checks described in those guides. Keep private planning, credentials, unpublished originals and local editor state outside this repository. Publishing and history replacement require explicit authorization.
